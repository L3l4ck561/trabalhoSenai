ROTA PRINCIPAL
APP = FLASK
	-> ‘/’ (VAI PARA O INDEX).
	->’/CADASTRAR-LIVRO’ (VERIFICA SE É O POST. SE    FOR, CONECTA COM O BANCO. SALVA OS DADOS. FECHA A CONEXÃO. REDIRECIONA PARA LISTAR-LIVROS.HTML)
	->’/LISTAR-LIVRO’ (FAZ A CONEXÃO COM O BANCO. SELECIONA SOMENTE OS LIVROS ATIVOS. CRIA UM VETOR. FECHA A CONEXÃO. ABRE NO LISTAR-LIVRO.HTML).
	->’/EXCLUIR-LIVRO’ (FAZ A CONEXÃO COM O BANCO. SELECIONA O LIVRO PELO ISBN E ATUALIZA PARA “ATIVO = 0”. Salva (commit). FECHA A CONEXÃO. ABRE O LISTAR-LIVRO.HTML).
	->’/EDITAR-LIVRO’ (VERIFICA O MÉTODO. RECEBE OS DADOS DO FORMULÁRIO. FAZ A CONEXÃO COM O BANCO. ATUALIZA OS DADOS COM OS DADOS DO FRONT END. EXECUTA E SALVA. REDIRECIONA PARA LISTAR-LIVRO.HTML.
		--> ELSE: (FAZ A CONEXÃO COM O BANCO.   MONTA A INSTRUÇÃO PARA TRAZER OS DADOS DO LIVRO. FECHA A CONEXÃO. REDIRECIONA PARA EDITAR-LIVRO.HTML.)
	->’/CADASTRAR-LEITOR’ (VERIFICA O MÉTODO POST. RECEBE OS DADOS DO FORM. FAZ A CONEXÃO COM O BANCO. INSERE OS DADOS NO BANCO. SALVA E FECHA A CONEXÃO. REDIRECIONA PARA LISTAR-LEITOR.HTML)
		--> ELSE: (REDIRECIONA PARA CADASTRAR-LEITOR.HTML)
	->’/LISTAR-LEITOR’(FAZ A CONEXÃO COM O BANCO. SELECIONA OS LEITORES COM “ATIVO = 1”. CRIA UM VETOR COM O RESULTADO DA BUSCA. FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA LISTAR-LEITOR.HTML).
	->’/EXCLUIR-LEITOR’(FAZ A CONEXÃO COM O BANCO. EXCLUI LOGICAMENTE O LEITOR (ATIVO = 0). SALVA E FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA LISTAR-LEITOR.HTML).
	->’/EDITAR-LEITOR’ (VERIFICA O MÉTODO. RECEBE OS DADOS DO FORM. FAZ A CONEXÃO COM O BANCO. ATUALIZA OS DADOS DO BANCO. SALVO(COMMIT). FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA LISTAR-LEITORES.HTML).
		--> ELSE: (FAZ A CONEXÃO COM O BANCO. MONTA A INSTRUÇÃO SQL PARA TRAZER OS DADOS. FECHA A CONEXÃO. REDIRECIONA PARA EDITAR-LEITOR.HTML).
- > ‘/REALIZAR-EMPRESTIMO’ (VERIFICA O MÉTODO POST. RECEBE OS DADOS DO FORM. FAZ A CONEXÃO COM O BANCO. MONTA A INSTRUÇÃO SQL QUE INSERE OS DADOS NO BANCO. EXECUTA E SALVA (COMMIT). FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA LISTAR-EMPRESTIMO.HTML.
		--> ELSE: (REDIRECIONA PARA A PÁGINA REALIZAR-EMPRESTIMO.HTML).
- > ‘/LISTAR-EMPRESTIMO’ (FAZ A CONEXÃO COM O BANCO. MONTA A INSTRUÇÃO QUE SELECIONA OS EMPRÉSTIMOS “ATIVO=1”. EXECUTA O COMANDO. FECHA A CONEXÃO COM O BANCO. RETORNA A LISTA DOS EMPRESTIMOS EM LISTAR-EMPRESTIMO.HTML).
- > ‘/EXCLUIR-EMPRESTIMO’ (CONECTA COM O BANCO. MONTA A INSTRUÇÃO SQL QUE EXCLUI LOGICAMENTE O EMPRÉSTIMO (ATIVO=0). EXECUTA E SALVA. FECHA O BANCO. REDIRECIONA PARA A PÁGINA LISTAR-EMPRESTIMO.HTML). 
- > ‘/EDITAR-EMPRESTIMO’ (VERIFICA O MÉTODO POST. RECEBE OS DADOS DO FORM. FAZ A CONEXÃO COM O BANCO. MONTA A INSTRUÇÃO SQL QUE ATUALIZA O EMPRÉSTIMO, SE O ID FOR CORRESPONDENTE. EXECUTA E SALVA A INSTRUÇÃO. FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA A PÁGINA LISTAR-EMPRESTIMO.HTML).
		--> ELSE: (FAZ A CONEXÃO COM O BANCO. MONTA A INSTRUÇÃO SQL QUE TRAZ OS DADOS DO EMPRESTIMO. FECHA A CONEXÃO COM O BANCO. REDIRECIONA PARA A PÁGINA EDITAR-EMPRESTIMO.HTML).
APP.RUN -> EXECUTA O WEBSITE.
