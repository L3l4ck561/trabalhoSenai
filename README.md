# 🎓 Atividades Acadêmicas – Curso Técnico em Análise e Desenvolvimento de Sistemas

Este repositório reúne as atividades, exercícios práticos, projetos e desafios desenvolvidos durante minha formação técnica no SENAI.

O objetivo deste material é documentar minha evolução técnica, consolidar conhecimentos adquiridos em sala de aula e manter um portfólio organizado das competências desenvolvidas ao longo do curso.

---

## 📚 Sobre o Curso

Durante o curso técnico em Análise e Desenvolvimento de Sistemas, foram abordados conteúdos teóricos e práticos voltados para a formação profissional na área de tecnologia, incluindo:

- Lógica de programação  
- Algoritmos e estruturas de dados  
- Desenvolvimento de sistemas  
- Banco de dados  
- Versionamento com Git  
- Boas práticas de desenvolvimento  
- Projetos práticos orientados
